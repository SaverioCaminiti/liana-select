Web component

liana-select

Swing through a tree of options and select one in a single, swift gesture.

Try it Getting started Examples Reference GitHub

Try it

Press on a category, slide right into its column, keep going, and release on a dish. That is one gesture, with a finger, a pen or the mouse. You can also tap one level at a time, and slide back left to change an earlier choice. With the keyboard, Tab into it, move with the arrow keys and confirm with Enter.

What it is

<liana-select> is a select for options organised as a tree: categories, subcategories, items. A native <select> flattens the tree into one long list, and nested menus need a tap per level. Here each level is a column, the next column opens while you are still pressing, and the path your finger draws is the path through the tree.

  • One gesture or many taps. Both lead to the same result, so nobody has to learn the gesture first.
  • Made to be large. It is closer to a textarea than to a dropdown: on a tablet it can take most of the screen.
  • No scrollbars. A long column scrolls with the height of the pointer, and deep trees shrink the columns on the left.
  • A real form control. It has a name and a value, is submitted and reset with its form, and dispatches input and change.
  • Keyboard and screen readers. It is one tab stop, works with the arrow keys, and is announced as a tree.
  • Plain HTML or any framework. It is a custom element, with no framework of its own to bring along.

Getting started

Import the package once, anywhere in your page or app. That registers the three elements. 

import 'liana-select';

Then declare the tree with nested <liana-group> and <liana-option> elements, and give the select a size: 

<liana-select name="dish" style="height: 24rem">
  <liana-group label="Pizza">
    <liana-option value="margherita">Margherita</liana-option>
    <liana-option value="marinara">Marinara</liana-option>
  </liana-group>
  <liana-option value="bread">Bread</liana-option>
</liana-select>

Read the value, or listen for it, as you would with a native select:

const select = document.querySelector('liana-select');
select.addEventListener('change', () => console.log(select.value));

The package is not published to npm yet. Until it is, clone the repository, run pnpm install and pnpm build, and import dist/liana-select.js. Its only dependency is Lit.

A tree in markup

Groups can contain options and other groups, to any depth. The label of a group is its label attribute, the label of an option is its text.

In a form

The value is submitted under the name of the select, and a reset brings back the option marked selected, here Water.

Setting the value from a script

Setting value opens the whole path to that option. An empty string clears the selection and goes back to the first column. Neither dispatches events: those are for what the user does.

Margherita Truffle Seafood Water Beer

Reacting to a choice

input and change are dispatched when a gesture ends on a different value, never while the pointer is still down. Releasing on a group clears the value. What happens next is up to you: this one adds the dish to a cart, then clears the select for the next dish.

Margherita Marinara Water Beer Bread

Cart: empty

Disabled items

A disabled option or group cannot be highlighted or selected. A group without children behaves the same way. The whole select can be disabled too.

Margherita Truffle (sold out) Tiramisu Bread

Long columns

There are no scrollbars. A column with more items than fit scrolls with the height of the pointer: the top of the column shows the first item, the bottom shows the last. Open Red and slide down. The more a column overflows, the less travel each item gets, so keep columns reasonably short.

White wine no. 1 White wine no. 2 Sparkling water

Deep trees in a narrow space

When the width allows it, the columns share it in equal parts, one per level of the tree. When it does not, as here, the current column stays whole and the ones on its left shrink: their text is clipped, never re-wrapped. Slide back left over the shrunk columns to go back, one level at a time.

Rome Viterbo Florence Siena Marseille Avignon Kyoto Osaka

With the keyboard

Click the button, then press Tab: the select shows the same focus ring as the other inputs of the page, and a cursor. The arrow keys move it, and nothing changes until Enter confirms an option. Escape, or leaving with Tab, restores the previous choice. Type the first letters of a label to jump to it.

Espresso Cappuccino Latte Green tea Black tea Water

Styling

Size the element like any block. By default its colours come from the focus ring of the browser, so they match the other inputs of the page; one custom property changes them all. Columns and items are exposed as parts.

Reference

<liana-select>

Attribute Property Description
name name Name under which the value is submitted with the form.
value value Value of the selected option, or an empty string. Setting it selects the option with that value; a value that no option has yet is applied when the option appears.
disabled disabled Ignores the pointer and is not submitted, as for any form control.
form Read only. The form the element belongs to, if any.
Event Description
input, change A gesture, or a keyboard navigation confirmed with Enter, ended on a value different from the one it started with. Both bubble. Read the new value from event.target.value.

Keyboard

The select is one tab stop. A cursor, shown like the item under the pointer, moves within the columns; nothing changes until an option is confirmed.

Key Effect
↓ ↑ Next or previous item of the column. Disabled items are skipped.
Home End First or last item of the column.
→ Into the group under the cursor, on its first item.
← Back to the previous column, on the group it came from.
Enter Space On an option: select it, set the value and dispatch the events. On a group: like →.
Escape Restore the selection from before the keys, and hide the cursor.
Letters Jump to the next item of the column whose label starts with the letters typed.
Tab Leave, restoring the selection if nothing was confirmed.

For assistive technology the select is a tree: each item is announced with its level, its position, and whether it is expanded or selected. Name it with an aria-label or with a <label for>.

<liana-group>

Attribute Description
label Text shown for the group.
disabled The group cannot be opened.

<liana-option>

Attribute Description
value Value of the select when this option is chosen. Defaults to the label.
label Text shown for the option. Defaults to its text content.
selected Marks the initial selection, also restored by a form reset. If several options have it, the last one wins.
disabled The option cannot be selected.

All the attributes of groups and options are also available as properties with the same name.

Styling

The element is a block, 20rem tall unless you size it. It follows the light or dark colour scheme of the page.

Custom property Default Description
--liana-item-min-height 2.75rem Minimum height of an item. Items grow to share the height of the column.
--liana-item-max-height none Maximum height of an item.
--liana-column-min-width 10rem Minimum width of a column. Below it, the columns on the left shrink.
--liana-column-collapsed-min-width 4rem Minimum width of a shrunk column.
--liana-accent-color focus ring Base of the colours below, and of the focus ring. By default the colour of the browser's own focus ring.
--liana-highlight-color half accent Background of the item under the pointer or the cursor: the accent mixed half and half with the background of the field.
--liana-highlight-text-color black or white Text of the item under the pointer or the cursor, whichever contrasts more.
--liana-selected-color light accent Background of a selected item.
Part Description
::part(column) A column of items.
::part(item) An option or a group.

Good to know

  • The element takes over every touch that starts on it, so the page cannot be scrolled by dragging on it. Leave some room around it.
  • Right-to-left layouts are not supported yet.
